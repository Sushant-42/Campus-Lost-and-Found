# CampusFind Assignment 4 — HTTP Test Transcript

## 1. Create a Claim — 201 Created

**Request:**

```http
POST http://localhost:5004/claims
Content-Type: application/json
Idempotency-Key: demo-claim-001

{
  "item_id": 1,
  "claimant_id": 1,
  "message": "I am claiming the HP laptop."
}
```

**Actual Response:**

```http
HTTP/1.1 201 CREATED
Location: http://localhost:5004/claims/1
Content-Type: application/json
```

```json
{
  "claimant_id": 1,
  "id": 1,
  "item_id": 1,
  "message": "I am claiming the HP laptop.",
  "status": "pending"
}
```

**Result:** PASS — Claim created successfully with HTTP 201 and a Location header.
